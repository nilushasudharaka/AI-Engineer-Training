# AI Engineer Training

## VisionRoot (Pvt) Ltd

This repository documents my three-week AI Engineering training journey at VisionRoot.

The training focuses on practical AI Engineering and AI-powered software development through theory, research, coding, experimentation, testing, and technical documentation.

## Training Duration

**3 Weeks / 15 Working Days**

## Primary Focus

* AI Engineering fundamentals
* Python
* APIs
* Generative AI
* Large Language Models (LLMs)
* Prompt Engineering
* Retrieval-Augmented Generation (RAG)
* AI Agents
* REST APIs
* AI evaluation
* AI security
* AI application optimization
* AI-powered software development

## Training Goal

The main goal of the training is to develop the ability to engineer reliable AI-powered software rather than simply using AI models.

By the end of the training, the expected outcome is a working AI application demonstrating LLM, RAG, and agentic capabilities.

## Daily Documentation Standard

Each training day documents:

* What I learned
* What I implemented
* What worked
* What failed
* How I investigated and solved problems
* What I would improve
* Git commit

## Training Roadmap

### Week 01 — AI & LLM Foundations

Understand AI Engineering fundamentals, become comfortable with Python and APIs, and build a basic LLM-powered assistant.

### Week 02 — RAG & AI Agents

Build grounded AI systems using retrieval and approved tools.

### Week 03 — Production AI Engineering

Evaluate, secure, optimize, and present a practical AI system.
